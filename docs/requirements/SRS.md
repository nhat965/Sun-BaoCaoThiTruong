# Software requirements specification

## Purpose

Mạch Thị Trường is a Vietnamese research and decision-support application, not a trading system. It exposes sourced market observations, deterministic indicators, related-news metadata, and reproducible reports.

## MVP functional requirements

1. Search supported Vietnamese symbols.
2. Retrieve daily OHLCV history through a connector manager.
3. Preserve source, observation timestamp, retrieval timestamp, and data mode.
4. Calculate SMA, EMA, RSI, MACD, Bollinger Bands, ATR, OBV and drawdown deterministically.
5. Retrieve related news metadata from a compliant feed.
6. Generate a structured Vietnamese analysis response and PDF report.
7. Render the same evidence in a responsive Vietnamese dashboard.
8. Surface missing, stale, fixture, and upstream-error states explicitly.

## Non-functional requirements

- Typed API under `/api/v1`, OpenAPI generated by FastAPI.
- Connector failures are isolated and translated into stable error responses.
- No credentials or full copyrighted articles are persisted.
- Formula tests use deterministic fixtures.
- Initial brokerage behavior is read-only; no order placement exists.
